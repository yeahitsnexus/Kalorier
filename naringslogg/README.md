# Næringlogg
1. Opprett Supabase-prosjekt, kjør `supabase/schema.sql` i SQL-editoren.
2. Kopier `.env.example` til `.env`, fyll inn URL og anon key.
3. Importer Matvaretabellen (matvaretabellen.no, åpne data, per 100 g) i `foods` med `owner = null`. MVP bruker faste måltids-ID 1–4.
4. Legg `icon-192.png` og `icon-512.png` i `public/`.
5. `npm install && npm run dev`
Ikke ferdig ennå: se svaret i chatten.
